# PySide6 Music Player

一个使用 PySide6 开发的桌面音乐播放器，支持MP3格式。

## 功能特性

支持常见功能：播放、暂停、随机/循环/单曲循环播放

支持创建/删除播放列表，添加歌曲到播放列表、从播放列表移除

支持歌曲搜索功能

支持音乐存储目录的指定，每次启动应用时动态监测存储目录中音乐的变化

## 安装

### 前置要求

- Python 3.11
- pip

### 安装依赖

```bash
pip install -r requirements.txt
```
